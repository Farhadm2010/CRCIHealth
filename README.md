# CRCIHealth

**Evidence-centered healthcare investigation and decision-support workflows with structured analysis and human oversight.**

CRCIHealth is a web application that helps healthcare professionals organize a case investigation. It brings case records, evidence, hypotheses, and an investigation plan into one structured workspace, keeps a full change history, and produces a consistent summary report. Professionals remain responsible for every judgement.

> This repository is a portfolio overview. It has documentation only. The application's source code is private and not published here. No patient information is included.

## Business problem

Complex case investigations involve many records, observations, and competing explanations. When this information is spread across notes and files, it is hard to see which evidence supports which hypothesis, what has changed, and how a conclusion was reached.

**Intended users:** healthcare professionals and investigators who need a structured, traceable way to work through a case.

## Main capabilities

Implemented in version 1. All analysis is entered and assessed by professionals; the software is manual and rule-based and has no AI features:

- **Case workspace:** create, search, and open investigation cases.
- **Records and evidence:** add and maintain medical records and evidence items for each case.
- **Structured analysis:** professionals record hypotheses, map mechanisms, and rank candidate root causes themselves.
- **Investigation roadmap:** plan and track the next investigation steps.
- **Summary report:** a consistent, rule-based case summary that can be previewed, printed, or downloaded.
- **Change history:** every editable item keeps a history of changes.
- **Accounts and case continuity:** professionals sign in, and their cases and reports remain available across sessions.
- **Tablet-friendly layout:** designed to work on iPad-sized screens as well as desktops.

The core workflow was checked end to end in a local software functional test that used synthetic data only. This was a software test, not a clinical study. That test covered creating a case, entering information, completing the investigation, reviewing the result, closing the case, and retrieving the report. CRCIHealth v1 is now frozen as a reference application.

## Scope and limitations

- CRCIHealth supports the investigation process. It does not diagnose conditions or recommend treatment.
- No clinical-validation claim is made, and no claim is made about clinical effectiveness.
- It is not presented as a regulated medical device, and it holds no healthcare certifications.

## AI capabilities and human-review boundaries

**Product behavior (v1):** CRCIHealth v1 has no AI features. Professionals enter the evidence and make the analysis themselves, and reports are generated by fixed rules, so the same inputs always produce the same report. The software makes no diagnoses and no treatment recommendations.

**How it was built:** AI coding tools supported development under my direction. That was part of how the software was built; it is not a feature of the product.

**Human oversight:**

- Professionals enter and assess all evidence and make every judgement. The system organizes and records their work.

## How it works

```text
Create case → Add records and evidence → Record hypotheses
→ Map mechanisms and rank root causes → Plan investigation steps
→ Review → Close case → Generate summary report
```

1. A professional creates a case.
2. They add the relevant records and evidence.
3. They record hypotheses and link them to supporting evidence.
4. They rank candidate root causes and plan the next investigation steps.
5. They review the case, close it, and generate the summary report.
